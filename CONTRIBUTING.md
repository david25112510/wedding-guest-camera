# Como contribuir

1. crie um fork;
2. abra uma branch descritiva;
3. mantenha as alterações pequenas e focadas;
4. execute `npm run build` e `npm run lint`;
5. descreva impacto visual, funcional e de dados;
6. abra um pull request.

Novas funcionalidades devem preservar acessibilidade, experiência mobile, compatibilidade com Cloudflare Workers e privacidade dos convidados.
