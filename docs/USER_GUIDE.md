# Guia de uso

## Para convidados

1. Escaneie o QR Code do casamento.
2. Digite seu nome e toque em **Entrar na experiência**.
3. Leia o aviso e toque em **Concordo e continuar**.
4. Use **Abrir câmera** para fotografar naquele momento ou **Escolher da galeria** para selecionar uma imagem já salva.
5. Aguarde a mensagem de confirmação antes de fechar a página.
6. Veja a foto no mural e acompanhe o número de imagens restantes.

Cada navegador pode enviar até 24 fotos no total. Câmera e galeria compartilham o mesmo saldo.

Antes do envio, o próprio navegador reduz a imagem para até 2.048 pixels e cria uma miniatura leve. O processo preserva boa qualidade para ampliação e reduz o consumo de dados móveis.

## Formatos aceitos

- JPEG/JPG;
- PNG;
- WebP;
- tamanho máximo de 12 MB para o arquivo original selecionado.

HEIC e HEIF não são aceitos diretamente. Se o celular não converter automaticamente, exporte ou compartilhe a imagem como JPEG.

## Para os organizadores

- mantenha a URL do evento privada até a validação final;
- teste o QR Code em pelo menos um Android e um iPhone;
- confirme a qualidade do Wi-Fi ou 4G no local;
- informe aos convidados quem poderá ver o mural;
- estabeleça um canal para solicitar remoção;
- acompanhe o uso de D1 e R2;
- defina quando as imagens serão arquivadas ou excluídas.

## Problemas comuns

### A câmera não abre

Confirme que o navegador possui permissão para usar a câmera e que o site está em HTTPS. Como alternativa, use **Escolher da galeria**.

### A foto não envia

Verifique a conexão, o formato e o tamanho. Aguarde alguns segundos e tente novamente.

### O contador não reiniciou

Esse é o comportamento esperado. O saldo é mantido no servidor e associado ao cookie do navegador.

### A foto não apareceu imediatamente

Use o botão de atualização do mural. A página também verifica novas imagens automaticamente.
