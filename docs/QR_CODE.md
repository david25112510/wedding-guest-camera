# QR Code definitivo

O QR Code oficial do casamento de **Lidieyne & Alexandre** abre diretamente a Câmera dos Convidados:

```text
https://wedding-guest-camera.davibh16.chatgpt.site
```

## Arquivos

- `public/qr-code-casamento.png`: 1.568 × 1.568 pixels, indicado para impressão e compartilhamento digital;
- `public/qr-code-casamento.svg`: versão vetorial, indicada para placas e materiais diagramados.

O código usa preto sobre branco, margem de quatro módulos e correção de erro alta. Não recorte a margem branca e não aplique transparência, distorção, filtros ou elementos sobre o código.

## Uso no evento

1. posicione o QR Code em uma área bem iluminada;
2. mantenha a URL escrita abaixo dele como alternativa;
3. imprima com pelo menos 4 cm de largura para leitura próxima;
4. para leitura a distância, aumente proporcionalmente e faça um teste no local;
5. teste com pelo menos um iPhone e um aparelho Android antes do evento.

O QR Code abre o site. Por segurança do Android e do iPhone, a câmera ou a galeria só é aberta depois que o convidado toca no botão correspondente.

## Segurança

O acesso público é destinado à experiência dos convidados e ao mural. O painel `/admin` continua protegido pelo login do proprietário, e as APIs administrativas validam a autorização novamente no servidor.
